## 📖 Overview

**Mi Tecnología** es una tienda de productos tecnológicos. Reúne en un solo lugar accesorios para celulares y computadores, cables de todo tipo, componentes de PC y dispositivos de Apple, Google Pixel y Xiaomi.

## 🛍 Catálogo

| Categoría | Productos |
|-----------|-----------|
| Cargadores | Cargadores de celulares |
| Protección para celulares | Carcasas, micas / protectores de pantalla, fundas de celular |
| Fundas | Fundas para celulares y computadores |
| Cables | Carga, transferencia de datos, ethernet, fibra óptica |
| Computación | Componentes de computadores |
| Dispositivos | Apple, Google Pixel, Xiaomi |

## 🚧 Estado del proyecto

Este repositorio aún no contiene código. Esta sección y las instrucciones de instalación, ejecución y despliegue se agregarán cuando exista una implementación.

## 🤝 Contributing

1. Haz un fork del repositorio.
2. Crea una rama para tu cambio: `git checkout -b mi-cambio`.
3. Haz commit de tus cambios y súbelos a tu fork.
4. Abre un Pull Request hacia `dev`.
